# sqlite-vector-rs v0.3.0 Improvements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the seven confirmed correctness bugs in the `vector` virtual table, make write throughput independent of table size, and add filtered KNN, exact search, runtime tuning, and vector utility functions (spec: `docs/superpowers/specs/2026-07-12-v0.3.0-improvements-design.md`).

**Architecture:** The vtab keeps its shadow-table design (`<t>_data` rows are transactional truth, `<t>_index` holds the serialized HNSW graph + JSON metadata). Correctness fixes land first with end-to-end SQL tests; then persistence becomes lazy (persist every `sync_every` changes, reconcile against `_data` on connect/rollback); then features build on the fixed foundation.

**Tech Stack:** Rust edition 2024, `sqlite3_ext` 0.2 (vtab + scalar API), `usearch` 2.24 (HNSW), `bytemuck`/`half`, `serde_json`. Tests via `rusqlite` (bundled) loading the built cdylib.

```rust
ChangeType::Update => {
    use sqlite3_ext::query::Statement;
    let old_rowid = info.rowid().get_i64();
    let args = info.args_mut();
    // args[0] = new rowid (NULL when unchanged), args[2] = vector,
    // args[3..3+N] = metadata columns.
    let new_rowid = if args[0].is_null() {
        old_rowid
    } else {
        args[0].get_i64()
    };
    let vector_blob = args[2].get_blob()?.to_vec();
    let num_meta = self.config.metadata_columns.len();

    self.config
        .vtype
        .validate_finite(&vector_blob, self.config.dim)
        .map_err(|e| Error::Module(e.to_string()))?;

    let meta_args = &mut args[3..3 + num_meta];
    let sql = ShadowOps::update_data_sql(&self.config);
    db.execute(&sql, |stmt: &mut Statement| {
        new_rowid.bind_param(&mut *stmt, 1)?;
        vector_blob.as_slice().bind_param(&mut *stmt, 2)?;
        let mut i = 3;
        for val in meta_args.iter_mut() {
            val.bind_param(&mut *stmt, i)?;
            i += 1;
        }
        old_rowid.bind_param(&mut *stmt, i)?;
        Ok(())
    })?;

    let state = self.state.borrow();
    state
        .index
        .remove(old_rowid as u64)
        .map_err(|e| Error::Module(e.to_string()))?;
    state
        .index
        .add(new_rowid as u64, &vector_blob)
        .map_err(|e| Error::Module(e.to_string()))?;
    drop(state);
    self.state.borrow_mut().dirty = true;

    Ok(new_rowid)
}
```

(Note: `validate_finite` already calls `validate_blob` internally — a single call suffices. If `db.execute` does not accept a bind closure in sqlite3_ext 0.2, use `db.query_row`'s sibling `db.execute` with a prepared statement: `let mut stmt = db.prepare(&sql)?;` bind via the same `bind_param` calls, then `stmt.execute(())`. Check `Connection::execute`'s `Params` impls; the `insert` call in `insert_into_data_shadow` proves closures implement `Params`.)

```rust
pub struct VectorTransaction {
    pub state: Arc<RefCell<IndexState>>,
    pub table_name: String,
    pub db: *const VTabConnection,
    pub snapshots: Vec<(i32, Vec<u8>)>,
}
```

(`begin()` in `mod.rs` initializes `snapshots: Vec::new()`.)

```rust
fn savepoint(&mut self, n: i32) -> Result<()> {
    let buf = self
        .state
        .borrow()
        .index
        .save_to_buffer()
        .map_err(|e| Error::Module(e.to_string()))?;
    self.snapshots.push((n, buf));
    Ok(())
}

fn release(&mut self, n: i32) -> Result<()> {
    self.snapshots.retain(|(sp, _)| *sp < n);
    Ok(())
}

fn rollback_to(&mut self, n: i32) -> Result<()> {
    let mut s = self.state.borrow_mut();
    if let Some(idx) = self.snapshots.iter().position(|(sp, _)| *sp >= n) {
        s.index
            .load_from_buffer(&self.snapshots[idx].1)
            .map_err(|e| Error::Module(e.to_string()))?;
        self.snapshots.truncate(idx + 1);
    } else if let Some(ref buf) = s.last_committed.clone() {
        s.index
            .load_from_buffer(buf)
            .map_err(|e| Error::Module(e.to_string()))?;
    }
    Ok(())
}
```

`rollback()` keeps its restore-from-`last_committed` body (now guaranteed `Some`); it no longer needs the `if let` fallback semantics but the code shape stays. Do **not** clear `dirty` in `rollback_to` — the transaction may still commit other changes.

```rust
use std::borrow::Cow;

/// Cast a byte blob to a typed slice, tolerating misaligned input.
///
/// SQLite blob pointers and `Vec<u8>` buffers are not guaranteed to be
/// aligned for T; fall back to an owned copy when they are not.
pub fn cast_blob<T: Pod>(blob: &[u8]) -> Cow<'_, [T]> {
    match bytemuck::try_cast_slice::<u8, T>(blob) {
        Ok(s) => Cow::Borrowed(s),
        Err(_) => Cow::Owned(
            blob.chunks_exact(std::mem::size_of::<T>())
                .map(bytemuck::pod_read_unaligned)
                .collect(),
        ),
    }
}
```

```rust
fn scalar_distance_pairs(
    pairs: impl Iterator<Item = (f32, f32)>,
    metric: DistanceMetric,
) -> f64 {
    match metric {
        DistanceMetric::L2 => pairs
            .map(|(x, y)| {
                let d = x - y;
                d * d
            })
            .sum::<f32>() as f64,
        DistanceMetric::InnerProduct => {
            -(pairs.map(|(x, y)| x * y).sum::<f32>() as f64)
        }
        DistanceMetric::Cosine => {
            let (dot, na, nb) = pairs.fold((0f32, 0f32, 0f32), |(d, a, b), (x, y)| {
                (d + x * y, a + x * x, b + y * y)
            });
            let denom = na.sqrt() * nb.sqrt();
            if denom == 0.0 { 1.0 } else { 1.0 - (dot / denom) as f64 }
        }
    }
}
```

```rust
if config.mode == IndexMode::Exact {
    // Brute-force streaming top-k with pushed filters applied in SQL.
    let mut scan_sql = format!("{} WHERE 1=1", sql.scan_all);
    for (col, op) in &filters {
        let name = &config.metadata_columns[col - 2].0;
        let sql_op = match *op { "eq" => "=", "gt" => ">", "ge" => ">=", "lt" => "<", "le" => "<=", _ => unreachable!() };
        scan_sql.push_str(&format!(" AND {name} {sql_op} ?"));
    }
    let mut stmt = db.prepare(&scan_sql)?;
    stmt.query(|q| {
        for (i, arg) in filter_args.iter_mut().enumerate() {
            arg.bind_param(q, (i + 1) as i32)?;
        }
        Ok(())
    })?;

    // Max-heap of size k ordered by distance (f64::total_cmp).
    struct Hit(f64, ScanRow);
    impl PartialEq for Hit { fn eq(&self, o: &Self) -> bool { self.0 == o.0 } }
    impl Eq for Hit {}
    impl PartialOrd for Hit { fn partial_cmp(&self, o: &Self) -> Option<std::cmp::Ordering> { Some(self.cmp(o)) } }
    impl Ord for Hit { fn cmp(&self, o: &Self) -> std::cmp::Ordering { self.0.total_cmp(&o.0) } }

    let mut heap = std::collections::BinaryHeap::with_capacity(k + 1);
    while let Some(row) = stmt.next()? {
        let r = read_scan_row(row, num_meta)?;
        let d = crate::distance::compute_distance(&query_blob, &r.vector, config.vtype, config.metric, config.dim)
            .map_err(|e| Error::Module(e.to_string()))?;
        heap.push(Hit(d, r));
        if heap.len() > k { heap.pop(); }
    }
    let mut rows: Vec<Hit> = heap.into_vec();
    rows.sort_by(|a, b| a.0.total_cmp(&b.0));
    let results = rows
        .into_iter()
        .map(|Hit(d, r)| KnnRow { id: r.id, vector: r.vector, metadata: r.metadata, distance: d })
        .collect();
    self.mode = CursorMode::Knn { results, pos: 0 };
    return Ok(());
}
```

```rust
fn blob_to_f64s(blob: &[u8], vtype: VectorType) -> Vec<f64> {
    use crate::types::cast_blob;
    match vtype {
        VectorType::Float2 => cast_blob::<half::f16>(blob).iter().map(|v| v.to_f64()).collect(),
        VectorType::Float4 => cast_blob::<f32>(blob).iter().map(|v| *v as f64).collect(),
        VectorType::Float8 => cast_blob::<f64>(blob).to_vec(),
        VectorType::Int1 => cast_blob::<i8>(blob).iter().map(|v| *v as f64).collect(),
        VectorType::Int2 => cast_blob::<i16>(blob).iter().map(|v| *v as f64).collect(),
        VectorType::Int4 => cast_blob::<i32>(blob).iter().map(|v| *v as f64).collect(),
    }
}

fn f64s_to_blob(values: &[f64], vtype: VectorType) -> Vec<u8> {
    match vtype {
        VectorType::Float2 => vtype.slice_to_blob(
            &values.iter().map(|v| half::f16::from_f64(*v)).collect::<Vec<_>>(),
        ),
        VectorType::Float4 => vtype.slice_to_blob(
            &values.iter().map(|v| *v as f32).collect::<Vec<_>>(),
        ),
        VectorType::Float8 => vtype.slice_to_blob(values),
        VectorType::Int1 => vtype.slice_to_blob(
            &values.iter().map(|v| *v as i8).collect::<Vec<_>>(),
        ),
        VectorType::Int2 => vtype.slice_to_blob(
            &values.iter().map(|v| *v as i16).collect::<Vec<_>>(),
        ),
        VectorType::Int4 => vtype.slice_to_blob(
```
